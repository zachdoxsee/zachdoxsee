# Zach Doxsee

I build websites and back-office software for small businesses and artists: storefronts and checkout, booking, crew scheduling, client portals. Most of it is Next.js on Supabase, Stripe and Vercel.

Client code stays private. Write-ups of that work are at [zachdoxsee.com](https://zachdoxsee.com).

## Public projects

- **[bartleby](https://github.com/zachdoxsee/bartleby)** turns a video or audio file into an editable transcript. Whisper runs on the visitor's device through Transformers.js. Live at [bartleby.tech](https://bartleby.tech).
- **[zdox-portfolio](https://github.com/zachdoxsee/zdox-portfolio)** holds two portfolio concepts. Studio Floor uses GSAP, Lenis and three.js. Wheel puts nine projects on a 3D wheel inside a WebGL room ([demo](https://zdox-wheel.vercel.app)).
- **[ppf-configurator-demo](https://github.com/zachdoxsee/ppf-configurator-demo)** is a paint-protection-film configurator for an automotive booking portal. Customers pick a body style and a package, then change coverage panel by panel across four SVG views.

## Stack

Next.js, React, TypeScript, Tailwind CSS, Supabase, Postgres, Stripe, Twilio, Resend, Vercel. GSAP, Motion and three.js for animation and 3D. Vitest and Playwright for tests.
